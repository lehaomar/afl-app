# AFL — Любительская Футбольная Лига 2026/2027

PWA-приложение для управления турниром команды **Paradaraya**.

---

## Быстрый старт

### 1. Установка зависимостей

Откройте **два терминала** в папке проекта.

**Терминал 1 — Backend:**
```bash
cd backend
npm install
npm run dev
```

**Терминал 2 — Frontend:**
```bash
cd frontend
npm install
npm run dev
```

### 2. Откройте приложение

Перейдите по адресу: **http://localhost:5173**

---

## Структура проекта

```
Paradaraya/
├── backend/
│   ├── routes/         # API маршруты
│   ├── middleware/     # JWT авторизация
│   ├── data/           # База данных SQLite (создаётся автоматически)
│   ├── uploads/        # Загруженные файлы
│   ├── backups/        # Автоматические бэкапы (каждый день в 03:00)
│   ├── database.js     # Инициализация БД
│   └── server.js       # Сервер Express
│
└── frontend/
    └── src/
        ├── api/        # Клиент для API
        ├── components/ # Общие компоненты
        └── pages/      # Страницы приложения
            ├── AllGames/   # Таблица / Результаты / Календарь
            ├── MyTeam/     # Бомбардиры / Галерея
            └── Admin/      # Панель администратора
```

## Возможности

### Публичная часть
- **Таблица** — автоматически рассчитывается по результатам матчей (В×3 + Н×1)
- **Результаты** — матчи разбиты по турам
- **Календарь** — только матчи команды Paradaraya (прошедшие и предстоящие)
- **Бомбардиры** — игроки Paradaraya с голами и ассистами
- **Галерея** — фото и видео от администратора

### Панель администратора
- Добавление/редактирование/удаление **команд**
- Добавление матчей с датой, временем и счётом
- Управление **игроками** и их статистикой
- Загрузка **фото и видео** с подписями

## PWA — установка на телефон

1. Откройте сайт в браузере на телефоне
2. Нажмите "Добавить на главный экран" (iOS Safari) или кнопку установки (Android Chrome)
3. Приложение установится как нативное

> Для работы PWA нужны иконки. Создайте папку `frontend/public/icons/` и добавьте:
> - `icon-192.png` (192×192 пикселей)
> - `icon-512.png` (512×512 пикселей)
>
> Можно сгенерировать на: https://realfavicongenerator.net

## Производственное развёртывание

### Вариант 1: Один сервер (простой)

```bash
# В папке frontend
npm run build

# В папке backend — измените .env:
NODE_ENV=production

# Запустите только backend (он будет отдавать и frontend)
npm start
```

Приложение будет доступно на **http://localhost:3001**

### Вариант 2: Отдельный домен (рекомендуется)

Разместите frontend на Vercel/Netlify, backend на Railway/Render/VPS.
В `.env` backend укажите домен frontend в CORS-настройках.

## Технологии

| Часть | Технология |
|-------|-----------|
| Backend | Node.js + Express |
| Database | SQLite (better-sqlite3) |
| Frontend | React 18 + Vite |
| Стили | Tailwind CSS |
| Авторизация | JWT (7 дней) |
| PWA | Service Worker + Web Manifest |
| Бэкапы | Автоматически каждую ночь → `backend/backups/` |

## Изменение настроек

Все настройки в файле `backend/.env`:

```env
PORT=3001                          # Порт backend-сервера
JWT_SECRET=ваш_секретный_ключ      # Секрет для JWT-токенов (смените!)
ADMIN_USERNAME=admin               # Логин администратора
ADMIN_PASSWORD=admin123            # Пароль (смените!)
NODE_ENV=development               # development / production
```
